# Suelo Común: Teoría de Organización Social Basada en Información y Responsabilidad Compartida

> **Estado del documento:** Versión 1.0 — Documento de trabajo para discusión pública y desarrollo colaborativo.

## ¿Qué es este proyecto?
Este repositorio alberga una propuesta teórica abierta que explora una pregunta fundamental: **¿qué necesita una persona para existir y qué relación debe establecer con los demás para vivir en sociedad sin caer en la dominación?**

El modelo plantea una transición desde la escasez gestionada por el mercado hacia una infraestructura social y de información transparente, donde:
* Las condiciones fundamentales de existencia (**el suelo común**) están garantizadas mediante la responsabilidad compartida y la producción coordinada.
* El trabajo socialmente necesario se reduce progresivamente gracias a la tecnología.
* La propiedad se redefine según su función (separando bienes personales/autonomía de grandes medios productivos).
* La Inteligencia Artificial y los sistemas de datos actúan como **herramientas de cálculo y coordinación democrática**, nunca como soberanos políticos.

## 🛠️ Cómo colaborar

Este documento fue concebido bajo el principio de **código abierto y poder distribuido**. No pretende ser una verdad dogmática, sino un punto de partida para la crítica y la mejora colectiva. 

Puedes contribuir de las siguientes maneras:
1. **Debatiendo puntos ciegos:** Abre un [Issue](../../issues) para discutir aspectos complejos como incentivos, gestión de la escasez, transición gradual o gobernanza del sistema.
2. **Proponiendo cambios:** Si deseas corregir, ampliar o reescribir alguna sección, envía un *Pull Request* (`PR`) con tus argumentos.
3. **Forks y experimentos:** Utiliza los principios de este documento para desarrollar simulaciones, modelos económicos cuantitativos o implementaciones a escala de comunidad voluntaria.
